# React Quize

### you think you know react prety well? test what you know about react with this react quize

## 📦 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/BRGOKA/react-quiz.git
   cd react-quiz
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   //run in a new terminal
   npm run server
   ```
